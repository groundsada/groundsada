# Mohammad Firas Sada

**Research Networking Systems Software Engineer | HPC & AI/ML | Research Networking | FPGA | Cloud & DevOps**

I'm a research networking systems engineer at **ESnet** (Lawrence Berkeley National Laboratory), working remotely. The work is science data movement and programmable networks: SENSE orchestration, transfer tooling for high-energy physics, and the plumbing between the tools researchers actually use. Before that I was at **SDSC/UCSD**, where I worked on all sorts of things for the National Research Platform: Kubernetes substrate and multi-tenancy, FABRIC integration, segment routing on FPGAs, CUDA tooling, Prometheus exporters for novel chips, and P4 machine learning on SmartNICs.
