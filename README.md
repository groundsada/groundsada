# Mohammad Firas Sada

**Research Networking Systems Software Engineer | HPC & AI/ML | FPGA | Cloud & DevOps**

Research networking systems software engineer at [ESnet](https://www.es.net/), operated by Lawrence Berkeley National Laboratory, working remotely on science data movement and programmable networks. Before ESnet I was at the San Diego Supercomputer Center, working with the National Research Platform, where I built and operated multi-tenant scientific Kubernetes infrastructure and researched networks from the packet path up.

## What I do

- **Now:** SENSE orchestration, transfer tooling for high-energy physics, and the infrastructure between the tools researchers actually use.
- **Before:** National Research Platform Kubernetes substrate and FABRIC integration, segment routing on FPGAs, CUDA tooling, Prometheus exporters for novel accelerators, P4 machine learning on SmartNICs.
